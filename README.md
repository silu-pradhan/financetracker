# Personal Finance Tracker

A clean, responsive expense and budget manager built with HTML, CSS, and vanilla JavaScript.

## Features

- Add, edit, and delete expenses
- Track total expenses, monthly budget, remaining balance, and transaction count
- Filter expenses by category
- Search expenses by title or category
- Category-wise spending chart using the Canvas API
- LocalStorage persistence after page refresh
- Dark and light theme toggle
- Export expenses as a CSV file
- Responsive layout for mobile, tablet, and desktop

## Tech Stack

- HTML5
- CSS3
- JavaScript ES6+
- Browser LocalStorage
- Canvas API

## Setup

Open `index.html` in any modern browser.

No installation or build step is required.

## Usage

1. Set a monthly budget.
2. Add expenses with title, amount, category, and date.
3. Use search or category filtering to inspect specific transactions.
4. Review spending distribution in the chart.
5. Export expenses as CSV when needed.
